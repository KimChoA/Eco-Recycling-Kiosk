## 💡 프로젝트 배경

본 프로젝트는 **1인 개인 프로젝트**로  
기획부터 UI 구성, 기능 구현까지 직접 진행했습니다.

졸업작품인

> **「라즈베리파이 5와 YOLOv8에 기반한 실시간 플라스틱 폐기물 분류 시스템」**

에서 아이디어를 얻어 개발했습니다.

졸업작품에서는 **Raspberry Pi 5와 YOLOv8**을 활용해  
`PET · PE · PP · PS` 플라스틱 폐기물을 실시간으로 분류했습니다.

이 경험을 바탕으로 단순한 **플라스틱 분류 기술**에서 끝내지 않고,

> **분리배출 → 보상 → 환경 교육 → 포인트 활용**

까지 이어지는 사용자 서비스로 확장하여  
**C# WinForms 기반 Eco Recycling Kiosk**를 구현했습니다.

특히 본 프로젝트에서는  
**화면 설계, 사용자 흐름 구성, 포인트 로직, 퀴즈, Eco Shop, 쿠폰 및 회원 관리 기능을 모두 1인으로 구현**했습니다.

## 📌 프로젝트 개요

**Eco Recycling Kiosk**는  
플라스틱 분리배출에 사용자 참여형 보상 시스템을 결합한  
**C# WinForms 기반 친환경 키오스크 프로그램**입니다.

단순히 플라스틱 종류를 확인하는 기능에서 끝나는 것이 아니라,

- 회원 관리
- PET · PE · PP · PS 분리배출
- 플라스틱 재질별 정보 제공
- 환경 O/X 퀴즈
- 포인트 적립
- 환경 기여도 계산
- 포인트 적립 확인
- Eco Shop
- 쿠폰 발급
- 마이페이지

까지 하나의 서비스 흐름으로 구성했습니다.

# ✨ 주요 기능

## 👤 1. 회원 관리

사용자별 서비스 이용 정보를 관리할 수 있도록  
회원 관리 기능을 구현했습니다.

- 회원가입
- 사용자 정보 수정
- 회원 탈퇴
- 사용자 정보 저장
- 사용자별 포인트 관리
- 사용자별 쿠폰 관리
- 마이페이지 연동

---

## ♻️ 2. 플라스틱 분리배출

사용자가 플라스틱 재질과 수량을 선택하여  
분리배출 결과를 처리할 수 있도록 구성했습니다.

지원 플라스틱:

- PET
- PE
- PP
- PS

재질과 수량에 따라  
포인트 및 환경 기여도가 계산되도록 구현했습니다.

---

## 🔍 3. 플라스틱 재질 정보 제공

사용자가 각 플라스틱 재질의 특성과  
재활용 정보를 확인할 수 있도록 구성했습니다.

- PET 정보
- PE 정보
- PP 정보
- PS 정보
- 재질별 특징
- 주요 사용 용도
- 재활용 관련 정보

단순히 분리배출만 진행하는 것이 아니라  
사용자가 플라스틱 재질에 대해 이해할 수 있도록 했습니다.

---

## 🧠 4. 환경 O/X 퀴즈

분리배출 이후 환경 관련 퀴즈를 제공하여  
환경 교육 요소를 추가했습니다.

- O / X 방식 퀴즈
- 10초 제한 시간
- 정답 여부 판단
- 정답 시 보너스 포인트 지급

분리배출 과정에 **환경 교육 + 보상 요소**를 추가하여  
사용자의 지속적인 참여를 유도하도록 구성했습니다.

---

## 💰 5. 포인트 시스템

사용자가 분리배출한 플라스틱의  
재질과 수량을 기준으로 포인트를 계산합니다.

- 재질별 포인트 계산
- 분리배출 수량 반영
- 퀴즈 보너스 포인트
- 누적 포인트 저장
- Eco Shop과 연동

적립한 포인트는  
Eco Shop에서 상품 구매에 사용할 수 있습니다.

---

## 🌱 6. 환경 기여도

사용자의 재활용 활동을  
환경 기여도로 확인할 수 있도록 구현했습니다.

- 분리배출 수량 누적
- CO₂ 감축량 표시
- 사용자별 환경 기여도 계산
- 마이페이지에서 누적 정보 확인

단순 포인트 보상 외에도  
사용자가 자신의 환경 기여도를 직접 확인할 수 있도록 했습니다.

---

## 🧾 7. 포인트 적립 확인증

분리배출 결과를 확인할 수 있도록  
확인증 형태의 화면을 구성했습니다.

- 분리배출한 플라스틱 수량
- 재질별 결과
- 적립 포인트
- 퀴즈 보너스
- 최종 적립 결과

키오스크 사용 후  
사용자가 자신의 분리배출 결과를 명확하게 확인할 수 있습니다.

---

## 🛒 8. Eco Shop

적립한 포인트를 이용해  
상품을 구매할 수 있는 기능입니다.

- 상품 목록 확인
- 상품별 필요 포인트 표시
- 보유 포인트 확인
- 포인트 사용
- 상품 구매
- 쿠폰 시스템 연동

포인트를 단순히 적립하는 것에서 끝나지 않고  
실제로 사용할 수 있는 보상 흐름을 구현했습니다.

---

## 🎟️ 9. 쿠폰 시스템

Eco Shop에서 구매한 상품은  
쿠폰 형태로 발급됩니다.

- 상품 구매 후 쿠폰 발급
- 사용자별 쿠폰 저장
- 보유 쿠폰 확인
- 마이페이지 연동

이를 통해

> **분리배출 → 포인트 적립 → 상품 구매 → 쿠폰 발급**

으로 이어지는 보상 구조를 구성했습니다.

---

## 🙋 10. 마이페이지

사용자가 자신의 정보를 한곳에서 확인할 수 있도록  
마이페이지를 구현했습니다.

- 사용자 정보
- 현재 보유 포인트
- 쿠폰 확인
- 환경 기여도 확인
- 회원정보 수정
- 회원 탈퇴

---
